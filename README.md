# bio_inspired_muscle
Bio-inspired muscle control for quadruped locomotion, project made by two robotics bachelor students.

**Target platform:** Unitree Go2 quadruped — simulated in MuJoCo.

For the detailed project plan, architecture, and active file list see [`python/README.md`](python/README.md).
